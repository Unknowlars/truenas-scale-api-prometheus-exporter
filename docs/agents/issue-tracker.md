# Issue tracker: local Markdown

Work items live under `.scratch/<feature>/`: `spec.md` records intent and
`issues/NN-slug.md` records one task per file. Use `Status: open`, `claimed`, or
`resolved`. Record blocking issue numbers and append conclusions under `Answer`.
The TrueNAS 27 migration specification is the owner's ten-phase modernization
request and accepted implementation plan; its durable evidence lives in
`docs/reviews/` and `docs/modernization/README.md`.

GitHub issues and pull requests may be inspected as evidence. Creating issues,
comments, or other external messages requires separate owner authorization.
