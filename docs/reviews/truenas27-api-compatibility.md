## Migration decisions

- Keep version-selected 25.10, 26.0 and 27 profiles. Never route unknown versions to the most permissive catalog.
- Prefer documented `auth.login_ex`/`API_KEY_PLAIN` when a username is configured. Authentication succeeds only for explicit `SUCCESS`. Preserve the existing key-only path for older deployments, without automatic downgrade after rejection.
- `virt.*` instance surfaces disappeared after 25.10. Use only reviewed `container.*` replacements and retain historical metric declarations; do not translate opaque payload fields by name similarity.
- Reporting graph names must come from the pinned enum. Historical `reporting.graphs` prose references are not proof that a method exists; the 27 reporting graph enum omits historical ARC graphs `arcactualrate`, `arcrate`, `arcresult`.
- Calls remain read-only and count/select projections remain mandatory for sensitive inventories. Optional failure must not suppress unrelated metrics.
