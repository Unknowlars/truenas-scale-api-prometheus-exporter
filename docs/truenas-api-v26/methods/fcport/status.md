# fcport.status

## Summary

Return the runtime status of Fibre Channel ports, including port state, type, speed, and connected sessions.

On an HA system, status is gathered from both controllers and reported per node.

## Required Roles

- `SHARING_ISCSI_TARGET_READ`

###### with_lun_access

- Schema name: `With Lun Access`
- Type: boolean
- Default: true

When `true`, only include Fibre Channel sessions that have access to at least one LUN (Logical Unit Number). When `false`, include all Fibre Channel sessions regardless of LUN access.
