# container.metrics

## Summary

This event is generated by a dynamic source. If you want to specify subscription params, subscribe to it using the name in the following format `container.metrics:{"param": "value"}`

## Required Roles

- `CONTAINER_READ`

## Schema

- Type: object

### Subscription parameters

- Schema name: `ContainersMetricsEventSourceArgs`
- Type: object

#### interval

- Schema name: `Interval`
- Type: integer
- Default: 2

Interval in seconds between metrics updates (minimum 2 seconds).
- Value must be greater or equal to `2`
