###### with_lun_access

- Schema name: `With Lun Access`
- Type: boolean
- Default: true

When `true`, only include Fibre Channel sessions that have access to at least one LUN (Logical Unit Number). When `false`, include all Fibre Channel sessions regardless of LUN access.
